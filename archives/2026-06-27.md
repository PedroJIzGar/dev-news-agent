## Top 3 noticias del día

### 1. Amazon Q Developer Flaw Could Let Malicious Repos Run Code via MCP Configs

**Score:** 9/10  
**Fuente:** The Hacker News  
**Categoría:** Security  
**URL:** https://thehackernews.com/2026/06/amazon-q-developer-flaw-could-let.html

**Resumen:**  
Se descubrió una vulnerabilidad crítica (CVE-2026-12957) en Amazon Q Developer que permitía a repositorios maliciosos ejecutar código y robar credenciales de la nube de un desarrollador. El fallo residía en la forma en que el asistente de codificación de IA manejaba los servidores Model Context Protocol (MCP). Amazon ya ha lanzado un parche.

**Por qué importa:**  
Esta vulnerabilidad destaca los riesgos de seguridad inherentes al uso de asistentes de IA en el desarrollo de software. La capacidad de un repositorio malicioso para ejecutar código y robar credenciales representa una amenaza significativa para la seguridad del desarrollador y la infraestructura de la nube.

### 2. Miasma Malware Targets npm Packages and GitHub Actions in Supply Chain Attack

**Score:** 9/10  
**Fuente:** The Hacker News  
**Categoría:** Security  
**URL:** https://thehackernews.com/2026/06/miasma-malware-targets-npm-packages-and.html

**Resumen:**  
Se ha descubierto una nueva evolución de ataques a la cadena de suministro que involucra al malware Miasma (parte de la familia Mini Shai-Hulud y Hades). Este malware ha comprometido paquetes npm, incluido LeoPlatform y RStreams, y ha explotado flujos de trabajo de GitHub Actions. El ataque también se ha propagado al ecosistema de Go.

**Por qué importa:**  
Este incidente subraya la creciente amenaza de los ataques a la cadena de suministro, que comprometen componentes de software legítimos para distribuir malware. La explotación de GitHub Actions y paquetes npm populares afecta directamente a los desarrolladores y sus pipelines de CI/CD.

### New Linux pedit COW Exploit Enables Root Access by Poisoning Cached Binaries

**Fuente:** The Hacker News  
**Categoría:** Security  
**Prioridad:** 🔴 Alta  
**Score:** 7/10  
**URL:** https://thehackernews.com/2026/06/new-linux-pedit-cow-exploit-enables.html

**Resumen:**  
Una nueva vulnerabilidad en el kernel de Linux, apodada 'pedit COW' (CVE-2026-46331), permite a un usuario local sin privilegios obtener acceso root en sistemas afectados. El exploit funciona corrompiendo la memoria caché de páginas al sobrescribir datos de binarios cacheados.

**Por qué importa:**  
Las vulnerabilidades de escalada de privilegios en el kernel de Linux son críticas ya que pueden permitir a atacantes obtener control total del sistema. La existencia de un exploit público aumenta el riesgo inmediato para los sistemas no parcheados.

**Acción recomendada:**  
Es fundamental aplicar los parches del kernel de Linux tan pronto como estén disponibles para mitigar esta vulnerabilidad. Los administradores de sistemas deben monitorizar activamente las actualizaciones de seguridad del kernel y aplicarlas de inmediato.

### New DirtyClone Linux Kernel Flaw Lets Local Users Gain Root via Cloned Packets

**Fuente:** The Hacker News  
**Categoría:** Security  
**Prioridad:** 🔴 Alta  
**Score:** 7/10  
**URL:** https://thehackernews.com/2026/06/new-dirtyclone-linux-kernel-flaw-lets.html

**Resumen:**  
Se ha descubierto una nueva vulnerabilidad de escalada de privilegios en el kernel de Linux, denominada DirtyClone (CVE-2026-43503). Esta falla permite a un usuario local corromper la memoria respaldada por archivos mediante paquetes de red clonados para obtener acceso root. Ya existe un exploit público.

**Por qué importa:**  
Al igual que otras vulnerabilidades del kernel, DirtyClone representa un riesgo significativo para la seguridad de los sistemas Linux, permitiendo a usuarios no privilegiados obtener control total del sistema. La disponibilidad de un exploit público acelera la necesidad de aplicar parches.

**Acción recomendada:**  
Se recomienda encarecidamente aplicar los parches de seguridad del kernel de Linux proporcionados por el proveedor de la distribución. Monitorizar y aplicar actualizaciones del kernel es esencial para proteger los sistemas contra este tipo de ataques.

## Top 3 noticias del día

### 1. New HTTP/2 Bomb Vulnerability Allows Remote DoS on NGINX, Apache, IIS, Envoy & Cloudflare

**Score:** 9/10  
**Fuente:** The Hacker News  
**Categoría:** Security  
**URL:** https://thehackernews.com/2026/06/new-http2-bomb-vulnerability-allows.html

**Resumen:**  
Una nueva vulnerabilidad denominada "HTTP/2 Bomb" afecta a servidores web populares como NGINX, Apache, IIS, Envoy y Cloudflare, permitiendo ataques remotos de denegación de servicio (DoS). La vulnerabilidad reside en la configuración predeterminada de HTTP/2 de estos servidores. Curiosamente, fue descubierta mediante el uso de OpenAI Codex.

**Por qué importa:**  
Esta vulnerabilidad puede causar indisponibilidad de servicios críticos. Dado que afecta a componentes de infraestructura web tan comunes, es vital para desarrolladores backend y de sistemas que gestionan la disponibilidad de aplicaciones.

### 2. Unpatched Windows Search URI Vulnerability Lets Attackers Steal NTLMv2 Hashes

**Score:** 8/10  
**Fuente:** The Hacker News  
**Categoría:** Security  
**URL:** https://thehackernews.com/2026/06/unpatched-windows-search-uri.html

**Resumen:**  
Investigadores de seguridad han descubierto una vulnerabilidad sin parchear en el manejador URI search: de Windows que podría permitir a atacantes robar hashes NTLMv2 de los usuarios. Este fallo es similar a una vulnerabilidad previa en la Herramienta Recortes de Windows.

**Acción recomendada:**

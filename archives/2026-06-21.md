## Top 3 noticias del día

### 1. Hackers Exploit Gravity SMTP WordPress Plugin Bug to Expose API Keys

**Score:** 4/10  
**Fuente:** The Hacker News  
**Categoría:** Seguridad  
**URL:** https://thehackernews.com/2026/06/hackers-exploit-gravity-smtp-wordpress.html

**Resumen:**  
Actores maliciosos están explotando una vulnerabilidad recientemente parcheada en el plugin Gravity SMTP para WordPress, que afecta a unos 100.000 sitios. Esta falla permite a atacantes no autenticados extraer datos sensibles como claves de API, secretos y tokens OAuth.

**Por qué importa:**  
Aunque el bug afecta a WordPress, la naturaleza de la vulnerabilidad (exposición de claves de API y secretos) es relevante para cualquier desarrollador que maneje credenciales y datos sensibles en sus aplicaciones, independientemente de la tecnología.



## Acciones recomendadas

- **Hackers Exploit Gravity SMTP WordPress Plugin Bug to Expose API Keys:** Revisar la seguridad de las aplicaciones para la gestión de claves de API y secretos. Mantener actualizados todos los plugins y dependencias, incluso si no son directamente parte de tu stack principal.

### 1. Attacker Used 4,837 Hijacked GitHub Accounts to Run a CI Secret Stealer in 1,806+ Repositories

**Score:** 9/10  
**Fuente:** The Hacker News  
**Categoría:** Seguridad  
**URL:** https://thehackernews.com/2026/11/4837-hijacked-github-accounts-ran-ci.html

**Resumen:**  
Un atacante utilizó credenciales robadas de 4.837 cuentas de GitHub para instalar un ladrón de secretos en más de 1.806 repositorios. Este ladrón está diseñado para sustraer secretos y credenciales en la nube a los que los flujos de trabajo de CI (Integración Continua) de un repositorio pueden acceder.

**Por qué importa:**  
Este incidente destaca una grave vulnerabilidad en la seguridad de las cuentas de desarrolladores y los repositorios en GitHub. El uso de cuentas secuestradas para infiltrar herramientas de robo de secretos en pipelines de CI representa una amenaza directa para la seguridad del código y los datos sensibles.

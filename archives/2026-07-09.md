### 2. GitHub 'Verified' Commits Can Be Rewritten Into New Hashes Without Breaking Signatures

**Score:** 10/10  
**Fuente:** The Hacker News  
**Categoría:** Security  
**URL:** https://thehackernews.com/2026/07/github-verified-commits-can-be.html

**Resumen:**  
Una nueva investigación demuestra que los commits firmados y marcados como 'Verified' en GitHub pueden ser reescritos con un hash diferente, manteniendo la validez de la firma digital y la información del commit. Esto ocurre sin necesidad de la clave de firma.

**Por qué importa:**  
Esto socava la confianza en la integridad de los commits firmados, que se utilizan para verificar la autenticidad y la autoría del código. La marca 'Verified' de GitHub podría ser engañosa si no se aborda esta vulnerabilidad.

### 3. Top AI Agents Built to Catch Malicious Code Can Be Tricked Into Running It

**Score:** 10/10  
**Fuente:** The Hacker News  
**Categoría:** AI for Developers  
**URL:** https://thehackernews.com/2026/07/friendly-fire-ai-agents-built-to-catch.html

### Microsoft Patches RoguePlanet Defender Flaw That Can Grant SYSTEM Privileges

**Fuente:** The Hacker News  
**Categoría:** Security  
**Prioridad:** 🔴 Alta  
**Score:** 9/10  
**URL:** https://thehackernews.com/2026/07/microsoft-patches-rogueplanet-defender.html

**Resumen:**  
Microsoft ha lanzado actualizaciones para corregir una vulnerabilidad crítica en Microsoft Defender, conocida como RoguePlanet, que permitía la escalada de privilegios a nivel de SYSTEM. La vulnerabilidad (CVE-2026-50656) reside en el Motor de Protección contra Malware y ya es pública.

**Por qué importa:**  
Las vulnerabilidades de escalada de privilegios son extremadamente peligrosas, ya que permiten a un atacante con acceso limitado obtener control total sobre un sistema. Proteger las defensas del propio sistema operativo es fundamental para la seguridad general.

**Acción recomendada:**  
Asegúrate de que tus sistemas Windows tengan aplicadas las últimas actualizaciones de seguridad de Microsoft Defender para mitigar esta vulnerabilidad.

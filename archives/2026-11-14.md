## Top 3 noticias del día

### 1. PostgreSQL Patches 52 Flaws, Including 22-Year-Old Bug Enabling Authenticated RCE

**Score:** 9/10  
**Fuente:** The Hacker News  
**Categoría:** Security  
**URL:** https://thehackernews.com/2026/11/postgresql-patches-52-flaws-including.html

**Resumen:**  
PostgreSQL ha lanzado parches para 52 vulnerabilidades, incluyendo una falla crítica (CVE-2026-6460) que permite a un usuario autenticado con permisos para crear objetos ejecutar código arbitrario en el servidor con privilegios del sistema operativo. Para una protección completa, también se requiere reconstruir las extensiones escritas en C.

**Por qué importa:**  
Las bases de datos son un componente fundamental de la mayoría de las aplicaciones. Una vulnerabilidad de ejecución remota de código (RCE) en PostgreSQL, especialmente una tan antigua y crítica, representa un riesgo de seguridad muy alto. Mantener PostgreSQL actualizado es crucial para proteger los datos y la infraestructura.

### 2. Critical Apache HTTP/2 Flaw Could Let Unauthenticated Attackers Execute Code Remotely

**Score:** 9/10  
**Fuente:** The Hacker News  
**Categoría:** Security  
**URL:** https://thehackernews.com/2026/11/critical-apache-http2-flaw-could-let.html

**Resumen:**  
Se ha descubierto una vulnerabilidad crítica (CVE-2026-119618) en el módulo HTTP/2 (mod_http2) del servidor Apache HTTP. Esta falla permite a un atacante remoto no autenticado ejecutar código arbitrario en el servidor. Afecta a las versiones 2.4.55 a 2.4.70 y ya ha sido corregida en la versión 2.4.71.

**Por qué importa:**  
Apache HTTP Server es un componente de infraestructura web muy utilizado. Una vulnerabilidad RCE no autenticada es extremadamente peligrosa, ya que puede ser explotada por cualquier persona con acceso al servidor. Proteger los servidores web es esencial para la disponibilidad y seguridad de las aplicaciones.

---

### 3. Critical Red Hat Quay Flaw Lets Attackers Read and Overwrite All Private Container Images in a Registry

**Score:** 8/10  
**Fuente:** The Hacker News  
**Categoría:** Security  
**URL:** https://thehackernews.com/2026/11/critical-red-hat-quay-flaw-lets.html

**Resumen:**  
Una falla crítica en Red Hat Quay permite a un atacante con acceso a un registro leer y sobrescribir todas las imágenes de contenedores privadas. Si el acceso anónimo está habilitado, el atacante no necesita credenciales. Red Hat ha lanzado compilaciones parcheadas.

**Por qué importa:**  
Quay es una plataforma de gestión de contenedores utilizada en muchos entornos de desarrollo y producción. La capacidad de leer y sobrescribir imágenes privadas de contenedores puede llevar al robo de propiedad intelectual, la inyección de código malicioso o la interrupción de servicios.



## Acciones recomendadas

- **PostgreSQL Patches 52 Flaws, Including 22-Year-Old Bug Enabling Authenticated RCE:** Actualizar PostgreSQL a la última versión parcheada inmediatamente. Revisar y reconstruir cualquier extensión C instalada en el servidor.
- **Critical Apache HTTP/2 Flaw Could Let Unauthenticated Attackers Execute Code Remotely:** Actualizar Apache HTTP Server a la versión 2.4.71 o superior si se utiliza el módulo HTTP/2. Asegurarse de que solo los servidores que requieren HTTP/2 lo tengan habilitado.
- **Critical Red Hat Quay Flaw Lets Attackers Read and Overwrite All Private Container Images in a Registry:** Actualizar Red Hat Quay a las versiones parcheadas recomendadas por Red Hat. Revisar la configuración de acceso anónimo y las credenciales de acceso a los registros.
- **Google Cloud Warns Three AMD Turin CPU Flaws Could Leak Data Across Processes in VMs:** Aplicar las actualizaciones del sistema operativo invitado en las VMs que se ejecutan en hardware afectado y realizar la acción de reinicio recomendada por Google Cloud.

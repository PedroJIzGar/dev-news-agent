### CISA Confirms Hackers Exploiting WordPress Core Flaw During Software Upgrades

**Fuente:** The Hacker News  
**Categoría:** Security  
**Prioridad:** 🔴 Alta  
**Score:** 8/10  
**URL:** https://thehackernews.com/2026/11/cisa-confirms-hackers-exploiting.html

**Resumen:**  
La CISA ha añadido una vulnerabilidad crítica en WordPress Core (CVE-2026-119977, CVSS 8.1) a su catálogo de Vulnerabilidades Explotadas Conocidas (KEV), indicando que está siendo activamente explotada. Se trata de una condición de carrera TOCTOU que permite la ejecución de código arbitrario.

**Por qué importa:**  
WordPress es un CMS muy popular. La explotación activa de una falla de ejecución de código arbitrario es una amenaza directa para cualquier sitio web que lo utilice. Entender las condiciones de carrera (race conditions) es importante para escribir código seguro.

**Acción recomendada:**  
Actualizar inmediatamente todos los sitios web basados en WordPress a la última versión. Monitorizar los registros de auditoría para detectar actividades sospechosas y considerar la implementación de Web Application Firewalls (WAF) para proteger contra este tipo de ataques.

### Critical Rails Flaw Lets Attackers Write Server Files via Crafted ImageMagick Uploads

**Fuente:** The Hacker News  
**Categoría:** Security  
**Prioridad:** 🔴 Alta  
**Score:** 8/10  
**URL:** https://thehackernews.com/2026/11/critical-rails-flaw-lets-attackers.html

**Resumen:**  
Una vulnerabilidad crítica en Ruby on Rails (en Active Storage, cuando se usa con ImageMagick) permite a atacantes no autenticados escribir archivos arbitrarios en el servidor mediante la subida de un archivo manipulado. Ya ha sido corregida en las versiones 8.1.4.1 y 8.0.5.2.

**Por qué importa:**  
Ruby on Rails es un framework popular para construir aplicaciones web. Una falla crítica que permite la escritura de archivos arbitrarios puede llevar a la ejecución de código y al compromiso total del servidor.

**Acción recomendada:**  
Actualizar las aplicaciones basadas en Ruby on Rails a las versiones 8.1.4.1 o 8.0.5.2 o superior. Si no es posible actualizar inmediatamente, revisar las configuraciones de ImageMagick y las validaciones de subida de archivos para mitigar el riesgo.

### Xen Hypervisor Flaws Let One Malicious VM Read and Write Any Other VM's Memory

**Fuente:** The Hacker News  
**Categoría:** Security  
**Prioridad:** 🔴 Alta  
**Score:** 8/10  
**URL:** https://thehackernews.com/2026/11/xen-hypervisor-flaws-let-one-malicious.html

**Resumen:**  
Dos fallos en el hipervisor Xen permiten que una máquina virtual (VM) maliciosa lea y escriba en la memoria de otras VMs en el mismo host, incluido dom0 (la VM administradora). Todas las versiones desde Xen 4.6 son vulnerables; los parches ya están disponibles.

**Por qué importa:**  
Estas vulnerabilidades son críticas para entornos de virtualización. Permitir que una VM controle la memoria de otras rompe el aislamiento fundamental de la virtualización y podría llevar al compromiso de todo el sistema.

**Acción recomendada:**  
Aplicar los parches de seguridad publicados por el Xen Project a todas las instalaciones de Xen. Si se utilizan servicios en la nube que se basan en Xen, verificar con el proveedor el estado de la aplicación de estos parches.

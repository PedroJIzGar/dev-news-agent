**Fuente:** The Hacker News  
**Categoría:** Seguridad  
**URL:** https://thehackernews.com/2026/10/researchers-demonstrate-node2shell-rce.html

**Resumen:**  
Investigadores de seguridad han demostrado un exploit RCE (Remote Code Execution) llamado 'Node2Shell' que puede ejecutarse en builds oficiales de Node.js (versión 24.22.0 para Linux arm64) utilizando datos Brotli maliciosamente creados. **Por qué importa:**  
Este es un fallo de seguridad crítico para cualquier desarrollador que utilice Node.js, especialmente en entornos Linux. La demostración en una imagen oficial sin configuraciones especiales subraya la urgencia.

### Critical Flaw in Python’s Popular Pillow Image Library Allows Code Execution via a Crafted Image

**Fuente:** The Hacker News  
**Categoría:** Seguridad  
**Prioridad:** 🔴 Alta  
**Score:** 9/10  
**URL:** https://thehackernews.com/2026/10/critical-flaw-in-pythons-popular-pillow.html

**Resumen:**  
Se ha descubierto una vulnerabilidad crítica (CVE-2026-112900) en la librería Pillow de Python, utilizada para el procesamiento de imágenes. Esta falla permite la ejecución remota de código (RCE) al procesar un archivo de imagen EPS especialmente diseñado, ya que el nombre del archivo se pasa directamente a Ghostscript sin validación.

**Por qué importa:**  
Pillow es una dependencia común en muchas aplicaciones Python, especialmente aquellas que manejan la carga o procesamiento de imágenes. Una vulnerabilidad RCE en una librería tan extendida es una amenaza seria para la seguridad de las aplicaciones que la utilizan, pudiendo llevar a la compromisión total del servidor.

**Acción recomendada:**  
Actualiza inmediatamente la librería Pillow a una versión que contenga el parche para CVE-2026-112900. Si la actualización inmediata no es posible, implementa medidas de seguridad adicionales como el sandboxing del proceso que maneja las imágenes o la validación estricta de los formatos de archivo permitidos.

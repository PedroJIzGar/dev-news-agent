## Top 3 noticias del día

### 1. CISA Flags TeamCity CVE-2026-63077 RCE Flaw Under Active Exploitation in the Wild

**Score:** 10/10  
**Fuente:** The Hacker News  
**Categoría:** Security  
**URL:** https://thehackernews.com/2026/08/cisa-flags-teamcity-cve-2026-63077-rce.html

**Resumen:**  
La CISA ha alertado sobre la explotación activa de una vulnerabilidad crítica (CVE-2026-63077) en versiones on-premise de JetBrains TeamCity. Esta falla de deserialización de datos no confiables permite a un atacante no autenticado ejecutar comandos de forma remota.

**Por qué importa:**  
TeamCity es una herramienta de integración continua popular. Una vulnerabilidad RCE (Remote Code Execution) activa bajo explotación representa un riesgo inmediato para las organizaciones que la utilizan, permitiendo a los atacantes tomar control de los servidores de compilación y potencialmente de toda la cadena de desarrollo.

### 2. Critical Gitea Flaw Let Unauthenticated Attackers Read Server Files via Org-Mode Markup

**Score:** 10/10  
**Fuente:** The Hacker News  
**Categoría:** Security  
**URL:** https://thehackernews.com/2026/08/critical-gitea-flaw-let-unauthenticated.html

**Resumen:**  
Una vulnerabilidad crítica (CVE-2026-59774) en Gitea permite a atacantes no autenticados leer cualquier archivo accesible por el usuario del servicio en versiones 1.22.1 a 1.27.0, utilizando un repositorio público y marcado Org-mode malicioso.

**Por qué importa:**  
Gitea es una plataforma Git autohospedada popular. Una vulnerabilidad que permite la lectura de archivos arbitrarios sin autenticación es extremadamente grave, ya que podría exponer código fuente sensible, archivos de configuración o datos del sistema. La facilidad de explotación (sin login, solo marcado Org-mode) la hace muy peligrosa.

### Attackers Compile khunt Inside Oracle to Turn SQL Injection Into Windows SYSTEM Access

**Fuente:** The Hacker News  
**Categoría:** Security  
**Prioridad:** 🔴 Alta  
**Score:** 9/10  
**URL:** https://thehackernews.com/2026/08/attackers-compile-khunt-inside-oracle.html

**Resumen:**  
Los atacantes explotan una vulnerabilidad de inyección SQL en una aplicación web para ejecutar código Java dentro de una base de datos Oracle. Esto les permite compilar y ejecutar herramientas post-explotación (khunt) desde el motor de la base de datos, logrando acceso SYSTEM de Windows.

**Por qué importa:**  
Este ataque demuestra una técnica avanzada de evasión y persistencia. Al ejecutar código dentro de la base de datos, los atacantes evitan escribir ejecutables en el disco, dificultando la detección por parte de software antivirus o EDR. La combinación de SQL injection con capacidades de ejecución de código dentro de Oracle es muy peligrosa.

**Acción recomendada:**  
Aplica parches de seguridad a tus aplicaciones web y bases de datos Oracle. Implementa defensas robustas contra inyecciones SQL. Revisa la configuración de la base de datos para limitar la capacidad de ejecutar código o compilar objetos desconocidos. Monitoriza la actividad inusual dentro de la base de datos.

**Prioridad:** 🔴 Alta  
**Score:** 8/10  
**URL:** https://thehackernews.com/2026/08/new-ovswrap-linux-kernel-flaw-lets.html

**Resumen:**

**Acción recomendada:**  
Aplica las actualizaciones del kernel de Linux tan pronto como estén disponibles y sean probadas. Revisa las configuraciones de Open vSwitch en tus sistemas. Limita los permisos de los usuarios locales a lo estrictamente necesario.

**URL:** https://thehackernews.com/2026/08/trojanized-npm-packages-decode-c2-ip.html

**Acción recomendada:**

Una operación de malware macOS llamada ClickFix utiliza más de 250 dominios que emplean 'fingerprinting' del navegador para mostrar señuelos de malware solo a usuarios seleccionados, ocultando las páginas maliciosas de crawlers y sandboxes.

**Por qué importa:**  
Esta técnica de ofuscación es un recordatorio de la sofisticación de las campañas de malware. Si bien el enfoque en macOS puede ser menos relevante para algunos desarrolladores, las tácticas de evasión son de interés general en ciberseguridad.

**Acción recomendada:**  
Mantén tu sistema operativo y navegador actualizados. Sé escéptico ante las solicitudes de descarga de software, especialmente si provienen de sitios web no solicitados o sospechosos. Utiliza software de seguridad de buena reputación.

### 1. Cisco Secure Email Gateway Flaw Exploited in the Wild, Enables Root Command Execution

**Score:** 10/10  
**Fuente:** The Hacker News  
**Categoría:** Security  
**URL:** https://thehackernews.com/2026/09/cisco-secure-email-gateway-flaw.html

**Resumen:**  
Una vulnerabilidad crítica (CVSS 9.8) en el software AsyncOS del Cisco Secure Email Gateway está siendo activamente explotada. Permite la ejecución de comandos de root a través de una validación insuficiente en la lógica de análisis de correo electrónico, afectando a atacantes no autenticados y remotos.

**Por qué importa:**  
Esta vulnerabilidad tiene un impacto directo en la seguridad del correo electrónico, un canal de comunicación fundamental para las empresas. La explotación en la naturaleza y la posibilidad de ejecución de comandos de root la convierten en una amenaza de alta prioridad para cualquier organización que utilice estos dispositivos.

### New DDRop Attack Breaks Intel TDX and AMD SEV-SNP Confidential Computing

**Fuente:** The Hacker News  
**Categoría:** Security  
**Prioridad:** 🟢 Baja  
**Score:** 3/10  
**URL:** https://thehackernews.com/2026/09/new-ddrop-attack-breaks-intel-tdx-and.html

**Resumen:**  
Investigadores han descubierto un nuevo ataque de hardware llamado DDRop que rompe la protección de memoria en las tecnologías de computación confidencial de Intel (TDX) y AMD (SEV-SNP). El ataque permite que las escrituras en memoria se omitan silenciosamente, haciendo que el procesador lea datos cifrados antiguos como si fueran actuales.

**Por qué importa:**  
Aunque es una vulnerabilidad de hardware interesante y avanzada, el impacto directo para la mayoría de los desarrolladores de software junior/intermedio es limitado, ya que requiere acceso físico o control de software previo al servidor. Sin embargo, es relevante para la seguridad a nivel de infraestructura.

**Acción recomendada:**  
Estar al tanto de las implicaciones de seguridad a nivel de hardware para la computación confidencial. Consultar con los administradores de sistemas o equipos de infraestructura sobre el estado de mitigación de este tipo de ataques si se utilizan estas tecnologías.

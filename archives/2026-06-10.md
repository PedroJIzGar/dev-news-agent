**Resumen:**  
Se han descubierto seis vulnerabilidades en protobuf.js, una implementación de Protocol Buffers para JavaScript y TypeScript, que podrían permitir la ejecución remota de código (RCE) y ataques de denegación de servicio (DoS) en aplicaciones Node.js.

**Categoría:** Seguridad  
**Prioridad:** 🟡 Media  
**Score:** 6/10  
**URL:** https://thehackernews.com/2026/06/new-frost-attack-lets-websites-track.html

**Resumen:**  
Un nuevo ataque llamado FROST utiliza JavaScript y el tiempo de acceso a la SSD para inferir qué sitios web y aplicaciones visita un usuario, sin necesidad de código nativo o permisos.

**Por qué importa:**

**Acción recomendada:**

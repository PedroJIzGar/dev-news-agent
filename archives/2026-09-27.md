### New Linux Kernel Flaw Gives ARM64 KVM Guests Read-Write Access to Host Memory

**Fuente:** The Hacker News  
**Categoría:** Security  
**Prioridad:** 🔴 Alta  
**Score:** 9/10  
**URL:** https://thehackernews.com/2026/09/new-linux-kernel-flaw-gives-arm64-kvm.html

**Resumen:**  
Una nueva vulnerabilidad en el código de virtualización KVM del kernel de Linux para procesadores ARM64 (CVE-2026-89775) permite a las máquinas virtuales invitadas acceder y modificar la memoria del host, lo que podría llevar a una escalada de privilegios o ejecución de código en el host.

**Por qué importa:**  
Esta falla de seguridad en el kernel de Linux, especialmente relevante para entornos de virtualización ARM64, puede comprometer la seguridad de todo el sistema host. Es crucial para los desarrolladores que trabajan con Docker, contenedores o infraestructuras de virtualización en plataformas ARM.

**Acción recomendada:**  
Aplicar los parches del kernel de Linux tan pronto como estén disponibles para las versiones afectadas. Monitorizar los registros del sistema en busca de actividades anómalas en entornos de virtualización KVM y considerar la segmentación de red si se utilizan hosts con esta configuración.

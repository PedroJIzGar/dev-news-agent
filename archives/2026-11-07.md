### 1. Claude Code's “Don't Ask Again” File Exposes Passwords and Keys in 1,122 Public Copies on GitHub

**Score:** 9/10  
**Fuente:** The Hacker News  
**Categoría:** Seguridad  
**URL:** https://thehackernews.com/2026/11/claude-codes-dont-ask-again-file.html

**Resumen:**  
Una función de Claude Code, al ser seleccionada para no preguntar de nuevo, guarda comandos que pueden incluir contraseñas y claves de API en archivos de configuración de proyectos. Se han encontrado 1,122 copias públicas de estos archivos en GitHub, exponiendo secretos.

**Por qué importa:**  
Demuestra un riesgo de seguridad significativo en herramientas de IA para desarrolladores. La exposición de credenciales en repositorios públicos puede llevar a accesos no autorizados y brechas de seguridad.

### 3. Hackers Target OpenSSH SSHole Flaw Within Hours of Disclosure, Gain Root on Honeypot

**Score:** 8/10  
**Fuente:** The Hacker News  
**Categoría:** Seguridad  
**URL:** https://thehackernews.com/2026/11/hackers-exploited-openssh-sshole-flaw.html

**Resumen:**  
Los atacantes están explotando activamente una vulnerabilidad recién descubierta en OpenSSH (denominada SSHole) que permite el acceso sin contraseña a sistemas que cumplen ciertas condiciones de configuración (usando musl C library con PAM deshabilitado).

**Por qué importa:**  
Esta vulnerabilidad de alto CVSS permite el acceso root a sistemas Linux desprotegidos. La explotación rápida por parte de atacantes subraya la importancia de aplicar parches de seguridad inmediatamente.

**Categoría:** Seguridad  
**Prioridad:** 🟢 Baja  
**Score:** 4/10  
**URL:** https://thehackernews.com/2026/11/installing-fix-for-exploited-wordpress.html

**Resumen:**  
Una vulnerabilidad en WordPress, que ya está siendo explotada, presenta un riesgo adicional durante el proceso de instalación del parche. El código sin parches se usa para desempaquetar los archivos de actualización, permitiendo ataques en ese breve lapso.

**Por qué importa:**

**Acción recomendada:**

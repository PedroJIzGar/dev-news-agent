### Researcher Publishes GitLab RCE PoC Letting Authenticated Users Run Commands as Git

**Fuente:** The Hacker News  
**Categoría:** Seguridad  
**Prioridad:** 🔴 Alta  
**Score:** 9/10  
**URL:** https://thehackernews.com/2026/07/researcher-publishes-gitlab-rce-poc.html

**Resumen:**  
Un investigador de seguridad ha publicado un prueba de concepto (PoC) para una vulnerabilidad de ejecución remota de código (RCE) en GitLab. Un usuario autenticado puede ejecutar comandos como el usuario 'git' en servidores GitLab auto-gestionados no parcheados, simplemente cometiendo dos Jupyter notebooks modificados.

**Por qué importa:**  
Esta vulnerabilidad permite a usuarios con permisos limitados escalar sus privilegios en sistemas GitLab, lo cual puede ser un punto de entrada para atacantes. Dado que GitLab es una plataforma popular para el desarrollo y la gestión de código, una brecha aquí puede tener implicaciones significativas.

**Acción recomendada:**  
Asegúrate de que tus servidores GitLab estén actualizados a la última versión. Revisa los registros de auditoría para detectar actividades sospechosas relacionadas con commits y ejecuciones de comandos.

### Bing Images Flaws Let Crafted SVGs Run Commands as SYSTEM on Microsoft's Servers

**Fuente:** The Hacker News  
**Categoría:** Seguridad  
**Prioridad:** 🔴 Alta  
**Score:** 9/10  
**URL:** https://thehackernews.com/2026/07/bing-images-flaws-let-crafted-svgs-run.html

**Resumen:**  
Se descubrió que fallos en la búsqueda de imágenes de Bing permitían la ejecución de comandos como SYSTEM en los servidores de procesamiento de imágenes de Microsoft y como root en máquinas Linux. La vulnerabilidad radicaba en el manejo de archivos SVG manipulados. Microsoft ha emitido dos CVEs críticos.

**Por qué importa:**  
Esta noticia resalta la importancia de la validación exhaustiva de entradas, incluso en funcionalidades aparentemente benignas como la búsqueda de imágenes. La explotación de estos fallos podría haber comprometido la infraestructura de Microsoft.

**Acción recomendada:**  
Presta atención a las prácticas de seguridad en el procesamiento de archivos de entrada y en la validación de datos. Mantente al día con los avisos de seguridad de Microsoft y otras grandes plataformas tecnológicas.

### Certighost Exploit Lets Low-Privileged Active Directory Users Impersonate a Domain Controller

**Fuente:** The Hacker News  
**Categoría:** Seguridad  
**Prioridad:** 🔴 Alta  
**Score:** 9/10  
**URL:** https://thehackernews.com/2026/07/certighost-exploit-lets-low-privileged.html

**Resumen:**  
Investigadores han publicado un exploit llamado 'Certighost' que permite a un usuario de Active Directory con bajos privilegios obtener un certificado para un Controlador de Dominio y autenticarse como tal. Esto puede llevar a la obtención de secretos de replicación de directorio (krbtgt) vía DCSync.

**Por qué importa:**  
Esta vulnerabilidad en Active Directory es extremadamente grave, ya que permite a un atacante interno con privilegios limitados obtener control administrativo sobre el dominio. La capacidad de impersonar a un controlador de dominio abre la puerta a ataques de movimiento lateral y exfiltración de datos sensibles.

**Acción recomendada:**  
Aplica parches y actualizaciones de seguridad a tus entornos Active Directory. Implementa el principio de mínimo privilegio para todas las cuentas de usuario. Considera realizar auditorías de seguridad regulares de tu infraestructura de AD.

### BlueNoroff Zoom Phishing Kit Profiles Crypto Wallets Before Malware Delivery

**Fuente:** The Hacker News  
**Categoría:** Seguridad  
**Prioridad:** 🔴 Alta  
**Score:** 8/10  
**URL:** https://thehackernews.com/2026/07/bluenoroff-zoom-phishing-kit-profiles.html

**Resumen:**  
Actores de amenaza norcoreanos, asociados con BlueNoroff, han implementado un kit de phishing activo que suplanta a plataformas de videoconferencia como Zoom y Microsoft Teams. Este kit perfila billeteras de criptomonedas antes de entregar malware, utilizando nombres de dominio mal escritos (typosquatting).

**Por qué importa:**  
El uso de tácticas de ingeniería social cada vez más sofisticadas y dirigidas, como la suplantación de plataformas populares y el enfoque en activos digitales, representa una amenaza creciente. La combinación de phishing y robo de criptomonedas es particularmente peligrosa.

**Acción recomendada:**  
Educa a los usuarios sobre las tácticas de phishing, especialmente las que involucran suplantación de identidad de servicios comunes. Implementa soluciones de seguridad de correo electrónico y monitorea la actividad de la red en busca de patrones de acceso sospechosos.

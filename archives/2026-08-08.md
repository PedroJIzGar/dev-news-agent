### 18-Year-Old Linux SCTP Flaw Could Let Local Users Gain Root and Escape Containers

**Fuente:** The Hacker News  
**Categoría:** Security  
**Prioridad:** 🔴 Alta  
**Score:** 9/10  
**URL:** https://thehackernews.com/2026/08/18-year-old-linux-sctp-flaw-could-let.html

**Resumen:**  
Una falla de seguridad de 18 años en el código de red SCTP de Linux, descubierta recientemente, permite a usuarios locales obtener privilegios de root e incluso escapar de contenedores. La corrección ya ha sido distribuida.

**Por qué importa:**  
El descubrimiento de una vulnerabilidad tan antigua y crítica en un componente fundamental de Linux como el manejo de red SCTP es notable. La capacidad de escalar privilegios y escapar de contenedores es una amenaza seria para cualquier entorno Linux, especialmente en orquestaciones como Docker o Kubernetes. La rápida distribución del parche es crucial.

**Acción recomendada:**  
Actualizar urgentemente los kernels de Linux a las versiones parcheadas (7.1.6, 6.18.42, 6.12.101, 6.6.148 o posteriores) si se utiliza el protocolo SCTP. Auditar los entornos de contenedores en busca de posibles compromisos y aplicar parches a nivel de host.

### Malware Can Abuse Windows Hello for Business Keys for Persistent Entra ID Access

**Fuente:** The Hacker News  
**Categoría:** Security  
**Prioridad:** 🔴 Alta  
**Score:** 9/10  
**URL:** https://thehackernews.com/2026/08/malware-can-abuse-windows-hello-for.html

**Resumen:**  
Se ha demostrado que el malware en una sesión de Windows iniciada puede utilizar las claves de Windows Hello for Business para autenticarse silenciosamente en Microsoft Entra ID, obteniendo acceso persistente a la nube.

**Por qué importa:**

Auditar los inicios de sesión y monitorear la actividad de cuentas sospechosas. Mantener los sistemas Windows y las políticas de Entra ID actualizadas.

Investigadores de seguridad han descubierto una falla en iCloud Private Relay de Apple que permite exponer la dirección IP real del usuario a través de bypass de proxies en WebKit. Esto ocurre cuando ciertas configuraciones de proxy se combinan con el servicio.

**Por qué importa:**  
Aunque iCloud Private Relay está diseñado para mejorar la privacidad, el descubrimiento de bypasses que exponen la IP real socava su propósito. Es importante que los usuarios estén al tanto de estas limitaciones y comprendan que ninguna solución de privacidad es infalible, especialmente cuando se interactúa con configuraciones de red complejas.

**Acción recomendada:**  
Estar informado sobre las limitaciones de las herramientas de privacidad. Considerar el uso de VPNs adicionales si se requiere un nivel de anonimato más alto. Mantener actualizados los dispositivos Apple y las aplicaciones que utilizan WebKit.

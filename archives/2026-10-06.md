### LibreOffice and OpenOffice Flaws Let Malicious Spreadsheets Run Code Without Macro Warnings

**Fuente:** The Hacker News  
**Categoría:** Seguridad  
**Prioridad:** 🔴 Alta  
**Score:** 8/10  
**URL:** https://thehackernews.com/2026/10/libreoffice-and-openoffice-flaws-let.html

**Resumen:**  
Se han descubierto vulnerabilidades en LibreOffice y OpenOffice que permiten la ejecución de código malicioso a través de hojas de cálculo sin advertencias de macros, siempre que la compatibilidad con Java esté habilitada.

**Por qué importa:**  
Aunque se enfoca en software de oficina, esta vulnerabilidad es un recordatorio de cómo las dependencias (en este caso, la compatibilidad con Java) pueden introducir vectores de ataque. Para desarrolladores Java, es importante ser conscientes de las implicaciones de seguridad de las bibliotecas y entornos que utilizan.

**Acción recomendada:**  
Si utilizas LibreOffice o OpenOffice y tienes habilitada la compatibilidad con Java, investiga las actualizaciones de seguridad o considera deshabilitar esta función si no es estrictamente necesaria. Ten precaución al abrir archivos de fuentes no confiables.

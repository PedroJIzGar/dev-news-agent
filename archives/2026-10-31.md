### Critical 16-Year-Old UEFI Flaw Can Run Code Before Secure Boot on Network-Booting Servers

**Fuente:** The Hacker News  
**Categoría:** Seguridad  
**Prioridad:** 🔴 Alta  
**Score:** 9/10  
**URL:** https://thehackernews.com/2026/10/critical-16-year-old-uefi-flaw-can-run.html

**Resumen:**  
Una falla crítica de 16 años en EDK II, el código base para firmware UEFI, permite a un atacante ejecutar código antes de que el sistema operativo cargue, pero solo en servidores que arrancan a través de la red.

**Por qué importa:**  
Las vulnerabilidades en el firmware UEFI son particularmente peligrosas ya que operan a un nivel muy bajo del sistema, antes incluso de que las defensas del sistema operativo estén activas. Esto podría permitir un compromiso profundo del sistema.

**Acción recomendada:**  
Mantener el firmware UEFI de los servidores actualizado. Para sistemas que arrancan por red, revisar la configuración de seguridad y las prácticas de red para mitigar riesgos.

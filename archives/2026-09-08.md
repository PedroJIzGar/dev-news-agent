## Top 3 noticias del día

### 1. Adobe Patches Magento Zero-Day Exploited to Deploy Rust Backdoor and PHP Web Shell

**Score:** 9/10  
**Fuente:** The Hacker News  
**Categoría:** Security  
**URL:** https://thehackernews.com/2026/09/adobe-patches-magento-zero-day.html

**Resumen:**  
Adobe ha lanzado parches para una vulnerabilidad crítica en Adobe Commerce y Magento Open Source, CVE-2026-75650 (CVSS 10.0), que ha sido explotada activamente para desplegar una puerta trasera Rust y un web shell PHP.

**Por qué importa:**  
Las vulnerabilidades zero-day explotadas activamente representan un riesgo significativo. Dado que afecta a Magento, una plataforma de comercio electrónico popular, y utiliza tecnologías como Rust y PHP, es crucial para los desarrolladores que trabajan con estas tecnologías o que gestionan entornos de comercio electrónico.

### 2. FreeIPA Flaw Chain Lets Anonymous Clients Create Reusable Administrator Credentials

**Score:** 9/10  
**Fuente:** The Hacker News  
**Categoría:** Security  
**URL:** https://thehackernews.com/2026/09/freeipa-flaw-chain-lets-anonymous.html

**Resumen:**  
Una cadena de vulnerabilidades en FreeIPA permite a clientes anónimos crear credenciales de administrador reutilizables y obtener acceso al grupo de administradores.

**Por qué importa:**  
Esta falla en FreeIPA, una solución de gestión de identidad común en entornos Linux, podría permitir a atacantes no autenticados obtener privilegios de administrador, comprometiendo la seguridad y la integridad de los sistemas.

### 3. PEEP Turns Chrome and Edge Into Post-Compromise Backdoors for Host Command Execution

**Score:** 9/10  
**Fuente:** The Hacker News  
**Categoría:** Security  
**URL:** https://thehackernews.com/2026/09/peep-turns-chrome-and-edge-into-post.html

**Resumen:**  
Se ha descubierto una herramienta post-explotación llamada PEEP que transforma los navegadores basados en Chromium (Chrome, Edge) en puertas traseras para la ejecución de comandos remotos.

**Por qué importa:**  
Esta herramienta representa una amenaza avanzada que puede secuestrar funcionalidades del navegador para obtener control persistente. Es relevante para los desarrolladores, ya que los navegadores son a menudo el punto de entrada o la superficie de ataque principal para muchas aplicaciones web.

### Grindr to Pay £26 Million to Settle U.K. Claims Over HIV Status Data Sharing

**Fuente:** The Hacker News  
**Categoría:** Security  
**Prioridad:** 🟡 Media  
**Score:** 6/10  
**URL:** https://thehackernews.com/2026/09/grindr-to-pay-26-million-to-settle-uk.html

**Resumen:**

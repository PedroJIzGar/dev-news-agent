### 1. PostgreSQL Fixes 12-Year-Old Logical Decoding Flaw Enabling Replication-Role Code Execution

**Score:** 9/10  
**Fuente:** The Hacker News  
**Categoría:** Security  
**URL:** https://thehackernews.com/2026/09/postgresql-fixes-12-year-old-logical.html

**Resumen:**  
Se ha descubierto y corregido una vulnerabilidad de seguridad de 12 años en PostgreSQL relacionada con la decodificación lógica. Esta falla permitía la ejecución de código arbitrario como usuario del sistema operativo si se poseía el atributo REPLICATION.

**Por qué importa:**  
Esta vulnerabilidad, presente desde PostgreSQL 9.4, podría haber sido explotada para obtener control del servidor de base de datos. Las actualizaciones abordan una falla crítica que afectaba la seguridad de la replicación.

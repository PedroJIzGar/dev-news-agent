## Top 3 noticias del día

### 1. Gheist Uses Stolen GitHub Tokens to Steal Private Repository Secrets via Actions Logs

**Score:** 10/10  
**Fuente:** The Hacker News  
**Categoría:** Seguridad  
**URL:** https://thehackernews.com/2026/10/gheist-uses-stolen-github-tokens-to.html

**Resumen:**  
Una campaña automatizada está utilizando tokens de GitHub robados para insertar flujos de trabajo que registran secretos de repositorios en los logs de GitHub Actions. Los atacantes luego descargan estos secretos antes de eliminar los registros de ejecución. Los ataques han tenido éxito en repositorios privados y entornos de GitHub Enterprise.

**Por qué importa:**  
Esta noticia es crítica porque expone una vulnerabilidad directa en el uso de tokens de GitHub, una herramienta fundamental para la automatización y la seguridad en el desarrollo. La filtración de secretos de repositorios privados puede tener consecuencias devastadoras para la seguridad de los proyectos y las empresas.

**Score:** 9/10  
**Fuente:** The Hacker News

### 3. Microsoft 365 Token-Replay Attacks Compromise 97 Accounts at 79 Organizations

**Score:** 9/10  
**Fuente:** The Hacker News  
**Categoría:** Seguridad  
**URL:** https://thehackernews.com/2026/10/microsoft-365-token-replay-attacks.html

**Resumen:**  
Investigadores de ciberseguridad han descubierto una campaña contra Microsoft 365 que utiliza ataques de retransmisión de tokens (Token-Replay) para capturar sesiones de inicio de sesión y acceder a cuentas de correo electrónico. Se han detectado 497 inicios de sesión exitosos en 79 organizaciones.

**Por qué importa:**  
Los ataques de retransmisión de tokens son una amenaza seria para las plataformas basadas en la nube como Microsoft 365, ya que eluden los mecanismos de autenticación tradicionales. Esto afecta directamente a la seguridad de las cuentas de correo electrónico y datos corporativos.



## Acciones recomendadas

- **Gheist Uses Stolen GitHub Tokens to Steal Private Repository Secrets via Actions Logs:** Revisar y rotar inmediatamente todos los tokens de GitHub en uso, especialmente aquellos asociados con GitHub Actions. Implementar la autenticación multifactor (MFA) y restringir los permisos de los tokens al mínimo necesario. Mantenerse informado sobre las últimas tácticas de ataque contra plataformas de desarrollo.
- **Malicious File in Downloads Folder Tries to Trick AI Coding Agent Into Installing Malware:** Ser muy cauteloso con los archivos y paquetes que se descargan y se utilizan, especialmente si se integran con herramientas de IA. Configurar las herramientas de IA para que requieran confirmación explícita antes de instalar o ejecutar código nuevo. Mantener actualizados tanto los sistemas de desarrollo como las herramientas de IA.
- **Microsoft 365 Token-Replay Attacks Compromise 97 Accounts at 79 Organizations:** Fortalecer las políticas de seguridad para el acceso a Microsoft 365. Habilitar y configurar la autenticación multifactor (MFA) en todos los usuarios. Estar atento a los intentos de phishing y a las comunicaciones sospechosas que puedan llevar a la captura de tokens de sesión.
- **Unpatched Tailscale SSH Flaws Could Let a Hacked Device Reach Root on Other Servers:** Asegurarse de que todas las instalaciones de Tailscale estén actualizadas a la última versión. Revisar la configuración de reenvío de puertos en Tailscale SSH y considerar deshabilitarlo si no es estrictamente necesario. Auditar regularmente los dispositivos conectados a la red Tailscale.

### Unpatched Tailscale SSH Flaws Could Let a Hacked Device Reach Root on Other Servers

**Fuente:** The Hacker News  
**Categoría:** Seguridad  
**Prioridad:** 🔴 Alta  
**Score:** 8/10  
**URL:** https://thehackernews.com/2026/10/unpatched-tailscale-ssh-flaws-could-let.html

**Resumen:**  
Fallos no parcheados en Tailscale SSH podrían permitir que un dispositivo comprometido obtenga acceso root en otros servidores dentro de la misma red. El ataque requiere que Tailscale SSH esté configurado con reenvío de puertos y que un atacante controle un dispositivo dentro de la red.

**Por qué importa:**  
Tailscale es una herramienta de red popular para crear redes privadas seguras. Las vulnerabilidades que permiten la escalada de privilegios y el acceso no autorizado dentro de estas redes son de alta preocupación para cualquier desarrollador o equipo que utilice la herramienta.

**Acción recomendada:**  
Asegurarse de que todas las instalaciones de Tailscale estén actualizadas a la última versión. Revisar la configuración de reenvío de puertos en Tailscale SSH y considerar deshabilitarlo si no es estrictamente necesario. Auditar regularmente los dispositivos conectados a la red Tailscale.



## 🟡 Media prioridad

### Two Critical Wasmtime Flaws Could Let Malicious WebAssembly Modules Escape Sandboxes

**Fuente:** The Hacker News  
**Categoría:** Seguridad  
**Prioridad:** 🟡 Media  
**Score:** 7/10  
**URL:** https://thehackernews.com/2026/10/two-critical-wasmtime-flaws-could-let.html

**Resumen:**  
Se han descubierto dos fallos críticos en Wasmtime, un runtime de WebAssembly, que podrían permitir que módulos maliciosos de WebAssembly escapen de sus entornos aislados (sandboxes). Un atacante necesitaría una compilación vulnerable de Wasmtime y, en uno de los casos, el fallo solo afecta a sistemas ARM64.

**Por qué importa:**  
WebAssembly (Wasm) es una tecnología cada vez más utilizada en diversos entornos, incluyendo el desarrollo web y como componente en aplicaciones más grandes. Las vulnerabilidades en su runtime pueden tener implicaciones de seguridad amplias, afectando la integridad y seguridad de las aplicaciones que lo utilizan.

**Acción recomendada:**  
Verificar si se está utilizando Wasmtime en algún proyecto. Si es así, actualizar a las versiones parcheadas tan pronto como estén disponibles. Estar atento a las actualizaciones de seguridad relacionadas con WebAssembly y sus runtimes.

### Between alerts: What Attackers Do in the Spaces Ordinary Detection Misses

**Fuente:** The Hacker News  
**Categoría:** Seguridad  
**Prioridad:** 🟡 Media  
**Score:** 6/10  
**URL:** https://thehackernews.com/2026/10/between-alerts-what-attackers-do-in.html

**Resumen:**  
Los equipos de seguridad a menudo luchan con la gran cantidad de alertas, perdiendo de vista cómo comenzaron los ataques o cómo progresaron. Los datos de red, como los de una plataforma de Network Detection and Response (NDR), son cruciales para conectar estas alertas y obtener una visión completa del incidente.

**Por qué importa:**  
Esta noticia resalta la importancia de tener una visibilidad completa del entorno de red y de las actividades de los atacantes, más allá de las alertas individuales. Comprender el 'espacio entre alertas' es fundamental para una defensa proactiva.

**Acción recomendada:**  
Considerar la implementación o mejora de herramientas de monitoreo de red y sistemas de detección y respuesta (NDR/XDR). Fomentar una cultura de análisis de incidentes que vaya más allá de la simple gestión de alertas, buscando comprender el contexto completo de las amenazas.



## 🟢 Baja prioridad

### uCreator Android Spyware Can Steal Telegram 2FA Passwords and Clone WeChat Accounts

**Fuente:** The Hacker News  
**Categoría:** Seguridad  
**Prioridad:** 🟢 Baja  
**Score:** 3/10  
**URL:** https://thehackernews.com/2026/10/ucreator-android-spyware-can-steal.html

**Resumen:**  
Un kit de spyware para Android llamado uCreator permite robar contraseñas de 2FA de Telegram y clonar cuentas de WeChat. El malware se oculta dentro de copias funcionales de estas aplicaciones, distribuidas fuera de las tiendas oficiales, o mediante una aplicación contenedora.

**Por qué importa:**  
Si bien este ataque se centra en Android y aplicaciones específicas, ilustra las tácticas que los ciberdelincuentes utilizan para comprometer información sensible, incluyendo credenciales de autenticación de dos factores.

**Acción recomendada:**  
Ser extremadamente cauteloso al instalar aplicaciones de fuentes no oficiales. Utilizar siempre las tiendas de aplicaciones oficiales y verificar la reputación y los permisos de las aplicaciones. Mantener las aplicaciones y el sistema operativo actualizados.

### 3. New Gitea RCE Lets Repository Writers Plant a Git Hook to Run Shell Commands

**Score:** 9/10  
**Fuente:** The Hacker News  
**Categoría:** Security  
**URL:** https://thehackernews.com/2026/07/new-gitea-rce-lets-repository-writers.html

**Resumen:**  
Gitea, una plataforma Git auto-alojada, ha parcheado una vulnerabilidad crítica de ejecución remota de código (RCE) (CVE-2026-60004). Permite a usuarios con permisos de escritura en un repositorio inyectar un 'Git hook' para ejecutar comandos del sistema.

**Por qué importa:**  
Esta vulnerabilidad es muy grave ya que un atacante con permisos limitados (escritura en un repo) puede escalar privilegios y ejecutar comandos arbitrarios en el servidor de Gitea, comprometiendo la infraestructura completa.

### Critical OpenWrt DHCPv6 Flaw Could Let Unauthenticated Attackers Run Code as Root

**Fuente:** The Hacker News  
**Categoría:** Security  
**Prioridad:** 🔴 Alta  
**Score:** 9/10  
**URL:** https://thehackernews.com/2026/07/critical-openwrt-dhcpv6-flaw-could-let.html

**Resumen:**  
Una falla crítica en el stack DHCPv6 de OpenWrt (CVE-2026-53921), calificada con 9.8 CVSS, permite a atacantes no autenticados ejecutar código como root. La vulnerabilidad se encuentra en el demonio `odhcpd`.

**Por qué importa:**  
OpenWrt es un sistema operativo popular para routers y dispositivos embebidos. Una vulnerabilidad de ejecución de código remoto como root en el servicio DHCPv6, que suele estar habilitado por defecto, expone a muchos dispositivos a un control total por parte de atacantes.

**Acción recomendada:**  
Aplica la actualización OpenWrt 24.10.8 a tus dispositivos. Si no puedes actualizar de inmediato, considera deshabilitar temporalmente el servidor DHCPv6 o restringir el acceso a él. Revisa el advisory de GitHub de OpenWrt.

### 24,650 Internet-Exposed BMCs Disclose IPMI Password Hashes Before Login

**Fuente:** The Hacker News  
**Categoría:** Security  
**Prioridad:** 🟢 Baja  
**Score:** 4/10  
**URL:** https://thehackernews.com/2026/07/24650-internet-exposed-bmcs-disclose.html

**Resumen:**  
Más de 36,000 interfaces de gestión de BMC (Baseboard Management Controller) expuestas a internet utilizan el protocolo IPMI, y 24,650 de ellas revelan hashes de contraseñas antes de iniciar sesión.

**Por qué importa:**  
Esto representa una superficie de ataque significativa para los servidores, ya que los hashes de contraseñas expuestos facilitan los ataques de fuerza bruta para obtener acceso no autorizado a la gestión del hardware del servidor.

**Acción recomendada:**  
Asegúrate de que las interfaces BMC en tus servidores no estén expuestas directamente a internet. Si es necesario el acceso remoto, utiliza VPNs seguras o herramientas de acceso remoto controladas. Deshabilita IPMI si no se utiliza.
